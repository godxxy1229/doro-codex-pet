## 경량화 (펫 크기 기준)

`tools/optimize.mjs`가 원본 doro.svg를 `src/doro-rig.svg`로 바꿉니다.

1. **격자 축소**: 좌표를 400×400 격자로 줄이고 정수로 반올림합니다. 셀에서 오차는 0.27px 이하입니다.
2. **경로 압축**: svgo로 경로를 상대 명령으로 압축합니다.
3. **노드 정리**: 모서리를 보존하며 노드를 다시 맞춥니다(`tools/simplify.mjs`). 노드가 줄어든 경로만 바꿉니다.
4. **선 정리**: 비슷한 선 두께를 하나로 통일하고(5.4~7.2 → 6), 같은 스타일의 선 경로를 병합합니다.
5. **홍조·홍채**: 13% 투명도 4겹 홍조를 방사형 그라디언트 1개로 바꿨습니다. 두 홍채 그라디언트도 하나로 합쳤습니다.
6. **원본과의 차이** (`qa/base-compare.json`, 셀 배율 216px 기준): 평균 픽셀 차는 흰 배경 2.1/255, 어두운 배경 1.8/255입니다. 대부분 선 위치가 1px 이하로 어긋난 것입니다.

## 리그 구조

원본 레이어(`docs/ORIGINAL.ko.md` 3장)를 그대로 유지했고, 아래 조각을 추가했습니다(`tools/rig-parts.mjs`).

- **보강** (기본 자세에서는 보이지 않음)
  - 다리 외곽선을 몸통 안쪽까지 연장하고, 다리 면은 외곽선 안쪽만 채웁니다. 다리를 ±17° 돌려도 흰 면이 삐져나오지 않습니다.
  - `under-lines`: 다리 아래 레이어에 깐 몸통 밑선입니다. 다리를 크게 돌리거나 숨겨도 몸통 선이 끊기지 않습니다.
  - 옆머리가 바깥으로 젖혀질 때 생기는 빈틈은 **그 아래 있어야 할 재질**로 메웁니다. 밑면은 두 종류입니다.
    - `fsl-under`·`fsr-under`(피부): 얼굴 피부(`face-skin`)를 바깥쪽으로 14 옮긴 사본입니다. 옆머리에 가려졌던 볼이 피부색으로 이어져 드러납니다. 클립 `fcl`·`fcr`로 볼 옆 구간(턱선 위)만 남깁니다.
    - `hsl-under`·`hsr-under`(머리카락): 움직이지 않는 옆머리 면 사본입니다. 정수리·관자놀이 이음새(클립 `hc`, y<215)만 메웁니다. 피부 밑면보다 아래 레이어라, 얼굴이 있는 곳은 피부가 덮습니다.
    - `build.mjs`가 **해당 옆머리가 바깥으로 돌 때만** 두 밑면을 자동으로 켭니다. 안쪽으로 돌 때 켜면 사본이 외곽선 밖으로 드러나 채색이 새기 때문입니다.
  - `crease-fl`: 왼쪽 앞다리 주름입니다. 다리를 크게 드는 waving에서는 숨깁니다.
- **표정** (doro는 눈을 감지 않고, 입은 모든 상태에서 평소 `:3`입니다)
  - `tears`: 뜬 눈 아래에 고인 눈물과, 눈 아래에서 볼 중간까지 흐르는 짧은 줄기(위는 가늘고 끝은 방울). failed의 시선 이동을 더해도 턱선보다 5 이상 위에 머뭅니다
- **도구**
  - `magnifier`: 돋보기(렌즈 반지름 43, 원래의 1.65배)입니다. 렌즈 중심은 왼쪽 눈 중심(94,217)과 같아서, 렌즈 속 큰 눈이 렌즈 한가운데에 보입니다. 눈 바로 아래의 `:3` 입은 왼쪽 일부가 렌즈 아래로 들어가고 오른쪽 끝만 렌즈 옆에 보입니다.
    - 렌즈 안에는 head를 왼쪽 눈 중심 기준 **1.4배로 확대한 영상**(`<use href="#head">`)을 `lens` 클립으로 넣습니다. 그 프레임의 고개·시선이 그대로 확대되므로, 렌즈 속 큰 눈이 실제 얼굴과 함께 움직입니다.
    - 렌즈를 움직일 때(돋보기 회전) 확대 영상을 담은 `lens-view`는 반대로 돌아 제자리에 남습니다. 그래서 렌즈 창만 눈 위를 미끄러집니다.
    - 그리는 순서는 손잡이 → 불투명 유리 바탕 → 확대 영상 → 옅은 유리 색조·테 → 반짝임입니다.
  - `paw-hold`: 돋보기를 쥔 둥근 앞발(벙어리장갑)입니다. 몸통과 분리돼 얼굴 왼쪽 아래 앞쪽에 있고, 손바닥 오른쪽 위로 엄지가 튀어나온 하나의 외곽선에 엄지 주름은 가는 선으로 그립니다.
    - 손잡이는 렌즈 아래에서 앞발 뒤를 지나 앞발 아래까지 나오고, 엄지가 그 오른쪽을 감쌉니다. 그래서 위·아래로 손잡이가 보여 쥔 느낌이 납니다.
  - `body-edge-fl`: 숨긴 왼쪽 앞다리가 원래 그려 주던 몸통 왼쪽 가장자리 선을 대신합니다. 몸통 그룹 안(머리 아래 레이어)이라 평소엔 옆머리 끝이 덮고, 고개가 기울면 그 아래로 몸통 윤곽이 이어져 보입니다.
  - `keyboard`: 키보드(`key-1`~`key-6`은 누른 키 표시)

기준점은 `src/poses.mjs`의 `PIVOTS`에 있습니다. 400 격자 기준이며, 원본 README 값의 절반입니다.

## 상태별 연출

| 상태 | 연출 |
|---|---|
| idle | 숨쉬기 squash 4%, 머리 bob, 고개 2°, 옆머리·리본 흔들림. 깜빡임은 없습니다 |
| running-left | 다리 3개가 교대로 ±17° 움직입니다. 한 주기에 몸이 두 번 튀고 앞으로 기울며, 머리카락·리본이 늦게 따라옵니다 |
| running-right | running-left를 프레임마다 좌우 반전했습니다. 프레임 순서는 유지합니다 |
| waving | 실제 왼쪽 앞다리를 앞으로 살짝 들어 까딱입니다(35° → 90° → 65° → 20°). 짧고 뭉툭한 비율 그대로이고 뿌리는 몸통·머리에 가려집니다. 65°·90°는 발 아랫선이 몸통 밑선과 매끄럽게 이어지는 각도입니다. 고개 6° |
| jumping | 웅크림 → 상승 32px → 정점 46px → 하강 → 같은 기준선에 착지 |
| failed | 눈을 뜬 채 눈물을 흘립니다. 입은 `:3` 그대로이고, 처진 속눈썹, 머리를 떨군 채 두 번 흐느낍니다 |
| waiting | 고개를 8° 갸웃하고 사용자 쪽을 봅니다. 입은 `:3` 그대로, 눈을 살짝 크게. 앞발로 바닥을 톡톡 두 번 칠 때는 앞다리를 45° 회전만 합니다(위로 끌어올리지 않아 꺾여 보이지 않음) |
| running | 키보드 위에서 앞발을 번갈아 누르고, 누른 키가 밝아집니다. 머리를 숙여 키보드를 봅니다 |
| review | 둥근 앞발(`paw-hold`)로 돋보기 손잡이를 감싸 쥡니다. 렌즈 중심이 왼쪽 눈과 같아 렌즈 속 1.4배로 확대된 눈이 중앙에 보입니다. 앞발과 돋보기를 함께 ±2.5° 돌려 렌즈가 눈 위를 미끄러지게 하며(렌즈 속 영상은 반대로 돌려 제자리), 시선 이동·고개 기울기와 함께 좌우로 훑습니다 |
| look | 몸은 고정합니다. 이목구비를 최대 18px(가로)·14px(세로) 옮기고, 머리는 0.4배로 따라오며 ±4° 기웁니다 |

## 다시 만들기

```bash
npm install
node tools/optimize.mjs   # doro.svg → src/doro-rig.svg (저장소 내부 source/doro.svg 사용)
node build.mjs            # 프레임 렌더 + final/spritesheet.png/webp
bash tools/validate.sh --gate   # 검증 + 프리뷰 + 최종 품질 게이트
```

- `node build.mjs idle waving`처럼 상태 이름을 주면 그 상태만 렌더합니다. 검수용 줄 이미지는 `qa/strips/`에 저장됩니다.
- `--dump-svg`를 주면 프레임 SVG를 `build/svg/`에 저장합니다.
- 검증 스크립트는 설치된 `~/.codex/plugins/.../work-pets/0.1.6`과 `~/.codex/skills/hatch-pet`의 스크립트를 수정 없이 씁니다.

## 알려진 한계

- **running-right의 장미·리본 위치**: doro는 원래 왼쪽을 보므로 running-right는 좌우 반전입니다. 그래서 이 행에서만 장미와 리본이 반대쪽에 보입니다.
- **시선 표현 방식**: doro의 눈에는 흰자가 없습니다. 그래서 시선은 이목구비 전체를 얼굴 안에서 옮기는 방식으로 표현합니다. 오른쪽·왼쪽 끝에서는 바깥쪽 눈이 옆머리에 일부 가려집니다.
- **돋보기 확대**: 렌즈 속은 head 전체를 1.4배 확대해 렌즈 모양으로 자른 영상입니다(`use` + `clipPath`). 실제 렌즈와 달리 확대 기준점(눈 중심)과 렌즈 중심이 조금 다릅니다.
- **추가 파츠 색**: 들어 올린 앞발, 도구, 눈물은 원본에 없는 추가 작도입니다. 색은 원본 팔레트에 맞춘 근사값입니다.
- **든 앞발이 보이는 범위**: waving·waiting의 앞발은 실제 다리(머리 아래 레이어)라, 옆머리 끝 아래로 나온 부분만 보입니다. review는 긴 팔(`paw-hold`)을 머리 위 레이어에 그립니다.
- **다리 드는 방식**: 앞다리는 기준점 회전만으로 듭니다. 위로 끌어올리면(ty) 발 아랫선과 몸통 밑선 사이에 계단이 생겨 꺾여 보입니다.
- **실루엣 홈의 배경 픽셀**: 리본 꼬리가 크게 젖혀지거나 다리가 접힐 때, 실루엣 가장자리의 좁은 홈에 배경 픽셀이 1~2개 갇힐 수 있습니다. 재질 안의 구멍은 아닙니다.
- **수작업 수정 시 주의**: `src/doro-rig.svg`는 `tools/optimize.mjs`가 생성합니다. 리그를 직접 고치면 다음 optimize 실행 때 덮어써집니다. 파츠는 `tools/rig-parts.mjs`에서 고치세요.
