# Doro for Codex Pets

An unofficial Doro companion for Codex.

[![Codex Pets](https://img.shields.io/badge/Codex%20Pets-Doro-f5c5cf?style=for-the-badge)](https://codex-pets.net/#/pets/doro-svg)

## Install

### CLI

Requires Node.js and npm.

```sh
npx codex-pets add doro-svg
```

### curl (macOS / Linux)

```sh
curl -fL "https://codex-pets.net/api/pets/doro-svg/download" \
  -o "/tmp/doro-svg.codex-pet.zip" &&
mkdir -p "$HOME/.codex/pets/doro-svg" &&
unzip -o "/tmp/doro-svg.codex-pet.zip" \
  -d "$HOME/.codex/pets/doro-svg"
```
